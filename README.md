# Ayubkhon Yuldashev Portfolio

Personal portfolio inspired by the layout and interactions of [Andrea Da Silva’s portfolio](https://adasilv2.framer.website/).

Built with plain HTML, CSS, and JavaScript. No build step or dependencies.

## Run locally

```sh
python3 -m http.server 8000 --directory dist
```

Open http://localhost:8000.

## Source

- `dist/index.html`: portfolio content and page structure
- `dist/style.css`: layout, responsive styling, and animations
- `dist/app.js`: project dialogs, navigation effects, tabs, and carousel
- `BRIEF.md` and `BRAND.md`: content and visual direction

Missing photos, project screenshots, résumé information, and recommendations are visibly marked as placeholders.

## Updates

After completing and checking an authorized portfolio change, commit and push it to this repository. Do not force push or overwrite unrelated changes.
